# Roadmap

## Store publication

- [ ] Add manifest icons (16, 32, 48, and 128 px) and store listing artwork/screenshots.
- [ ] Publish a privacy policy and support URL that explain user-configured TTS endpoints, optional API keys, and article-text handling.
- [ ] Add a versioned release-package command that builds, verifies, and creates a ZIP with `manifest.json` at its root.
- [ ] Prepare Chrome Web Store review instructions, including the user-configured endpoint flow and permission justifications.
- [ ] Register a Chrome Web Store developer account, complete listing/privacy/distribution fields, and submit the release ZIP.
- [ ] Register Microsoft Partner Center, reuse the Chrome-compatible ZIP, complete Edge listing/privacy/certification fields, and submit.

Store release work is deferred until the extension's browser integration is stable.
